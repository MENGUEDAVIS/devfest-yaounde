# DevFest Yaoundé

This repo holds two things:
- **`devfest-yaounde-web/`** — the active project. This is the real site, the reusable multi-year template. Start there.
- **`legacy/`** — an earlier, partial implementation, archived as-is. Not used as a reference for the current build. See `devfest-yaounde-web/docs/decisions/0001-initial-scaffold.md` for why.

If you're looking to run, build, or contribute to the site, go to [`devfest-yaounde-web/README.md`](devfest-yaounde-web/README.md).

## Status

**The main site is built.** Home, Schedule, Speakers, Team and FAQs are complete in both French and English. Tickets, Shop and the DP generator remain placeholder routes, blocked on the payment/auth decision (`devfest-yaounde-web/docs/decisions/0003-payments-and-auth.md`).

See [the project README](devfest-yaounde-web/README.md#status) for the page-by-page breakdown and the systems behind it.
